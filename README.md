# Aishwarya Saranga - Personal Portfolio

Full Stack Development, Assignment-1 (B.E. CSE, VII Sem).
Built with HTML5, CSS3, Bootstrap 5 and JavaScript ES6+.

## Run locally
1. Open the folder in VS Code.
2. Install the **Live Server** extension, right-click `index.html`, choose **Open with Live Server**.
   (Opening `index.html` directly in a browser also works.)

## Structure
- `index.html` - semantic page structure
- `css/style.css` - theme tokens, Flexbox/Grid, media queries
- `js/script.js` - rendering, filter, theme switch, validation
- `assets/` - resume PDF and images

## Before submitting
- Replace the `your-username` GitHub links in `js/script.js`.
- Add your photo in `assets/images/` and swap it into the hero.
